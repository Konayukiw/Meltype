Meltype
=======

雪解けのように、半角/全角の壁を溶かす日本語入力。

半角/全角 キーを押さなくても、日本語と英語を打ち分けられるようにする Windows 用のツールです。
詳しい使い方: https://github.com/yksr-melt/Meltype/blob/main/docs/USAGE.md

※ 以前「AutoIME」という名前のテスト版を使っていた方: Install.cmd を実行すると古い AutoIME は自動で片付けられ、
   設定と学習データは引き継がれます。

■ 必要なもの
・Windows 10 / 11 (64bit)
・Microsoft IME (Windows 標準の日本語入力)
  (.NET は同梱しているので、別途インストールは不要です)

■ インストール
1. この zip をどこかに展開する
2. Install.cmd をダブルクリック
   (「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」)
   管理者として実行する必要はありません (ふつうにダブルクリックでインストールできます)。
   「Meltype を終了できませんでした」と出たら、タスクトレイの Meltype のアイコンを右クリック →「終了」してから
   もう一度 Install.cmd を実行してください (前に管理者として実行したことがあるときに出ます)。
3. 画面右下のタスクトレイに「あ」のアイコンが出れば動いています
   Windows の起動時にも自動で起動します

■ Meltype IME (入力欄に直接入力)
インストールの途中で「Meltype IME を Windows に登録します」と出て、管理者権限の確認が出ます。
「はい」を選ぶと、打った文字が入力欄にそのまま下線付きで入り、変換の候補は入力位置の下に一覧で出るようになります。
・Win + Space で「Meltype」を選んで使います
・アイコンを右クリック →「Meltype キーボード (変換ボックスで入力)」を選ぶと、下の「使い方」の方式に戻せます
・「いいえ」を選んでも、下の「使い方」の方式で使えます (Install.cmd をもう一度実行すると、また聞きます)

■ 使い方
※ 「ウイルスを検出しました」などの脅威検出は、SmartScreen の警告とは別です。
   Windows セキュリティ →「ウイルスと脅威の防止」→「保護の更新」で定義を更新し、公式の ZIP を再ダウンロードして再検査してください。
   誤検知かどうかは検出名だけでは判断できません。保護を無効にしたり除外・許可に変更したりせず、
   Windows セキュリティの「保護の履歴」で検出名を確認し、版と検出名を報告してください。
   報告先: https://github.com/yksr-melt/Meltype/issues (個人名・パス・ダウンロード URL の一時トークンは隠してください)

メモ帳やブラウザの入力欄で、IME を気にせずそのままローマ字で打ってください。
・日本語はかなで、英単語 (google, hello など) は英字のまま、カーソルの下の変換ボックスに出ます
・Enter で確定、Space で漢字に変換 (英単語のときは確定して空白)
・よく使う言葉は、アイコンを右クリック →「ユーザー辞書...」で登録できます
・変換中は ← → で文節を選び、Space / ↓ で候補を切り替え、Shift + ← → で区切りを変えられます
・BackSpace は 1 音ずつ消えます、Esc で取り消し
・F7 でカタカナ、F10 で英字
・！ ？ ～ は Shift を押して打つと全角 (英文の後は半角)
・Shift を押して打った大文字で始まる語 (Google, W など) は英語
・小書き文字は x / l (xa, la = ぁ、ltu = っ)
・よくある書き間違い (ブレスレッド、シュミレーション など) は「もしかして: ブレスレット (Tab)」と出るので、Tab で直せます
・変換して Space / ↓ で候補を切り替えると、絵文字・顔文字も出ます (えがお → 😊、かおもじ → (^^) など)
・VS Code やターミナルでは基本は英数のままで、コメント (// や #) と "…" の中だけ日本語になります
  (コードの行で 半角/全角 を押すと、その行だけ日本語で打てます)
  (VS Code のチャット欄や Claude Code など AI への入力は、日本語が基本のままです)
・英語とも日本語とも読める語 (api など) は、F10 で英字にするか、Space を連打して候補の最後の英字を選んで確定すると、次から英字になります (F6 でかなにすると次からかな)
・半角/全角 : 英数 (そのまま入力) ⇔ 日本語
・Ctrl + 半角/全角 : Meltype 自体の有効 / 無効 (トレイのアイコンのダブルクリックでも同じ)

■ 今のモード (日本語 / 英数) の見分け方
・タスクバーの Windows の IME の表示は、Meltype が動いている間は常に「A」になります (故障ではありません)。
  Meltype が Windows の IME を OFF にして、代わりに入力を受け持っているためです。
・今のモードは次のどちらかで確認してください。
  - 入力欄をクリックしたときと 半角/全角 を押したとき、カーソルの近くに「あ」(日本語) か「A」(英数) が一瞬出ます
  - タスクトレイの Meltype のアイコン (日本語は「あ」、英数は「A」)
    Windows 10 では最初「^」の中に隠れていることがあるので、ドラッグしてタスクバーに出しておくと便利です
・タスクバーの IME の「A」が紛らわしい場合は、Windows の設定で非表示にできます
  (Windows 10: 設定 → 個人用設定 → タスクバー → システム アイコンのオン/オフ → 「入力インジケーター」をオフ)
  ※ Meltype を使わないときに IME の状態が見えなくなるので、お好みで

■ 自動判定の強さ
アイコンを右クリック →「自動判定の強さ」で選べます (設定画面の「判定」でも同じ)。
・積極的 : 英語らしければすぐ英字にする
・標準   : 既定。no / to / ga のような短い語は、前後が英語 (英文の途中) のときだけ英字
・慎重   : 確信度が高いときだけ英字にする
・手動   : 自動では英字にしない。変換ボックスの下に「Tab → google (英字に)」と提案が出るので、Tab で英字にする
英単語の判定には、同梱の辞書に加えて Windows の英語スペルチェッカーを使います。

■ かな入力 (α版: 試験中)
設定の「入力方式」を「かな入力 (JIS)」にすると、JIS かな配列で入力できます
(Shift+E = ぃ、Shift+Z = っ、Shift + ね = 、)。打ったキーの英字が英単語 (google など) なら英字で見せます。
自動判定の強さもローマ字入力と同じように効きます。

■ Google 日本語入力など、ほかの IME と併用するとき
Meltype が有効な間は、Windows の IME (Microsoft IME・Google 日本語入力) を自動で OFF にします。
ほかの IME を使いたいときは Ctrl + 半角/全角 で Meltype を一時停止してください。

■ おかしな動きがあったら
タスクトレイのアイコンを右クリック →「不具合の報告・提案...」から GitHub で報告できます。
次の 3 つを書いてもらえると助かります。
1. どのアプリで (メモ帳 / Chrome / Discord など)
2. 何と打って (例: kyouhagoogle と打って Enter)
3. どうなったか (例: 「今日はごおｇぇ」になった)
あわせて、右クリック →「ログ / 判定理由...」→「コピー」で、ログを貼り付けてもらえるとさらに助かります。
(ログには直前に打った文字の一部が含まれます。気になる部分は消してから送ってください)

■ 保存されるデータ
設定と学習データは %LOCALAPPDATA%\Meltype に保存されます。打った内容をネットワークに送ることはありません。
通信するのは、新しい版があるかを GitHub に確かめるときだけです (アイコンを右クリック →「更新」→「自動で更新する」で止められます)。

■ アンインストール
タスクトレイの Meltype のアイコンを右クリック →「アンインストール...」を選びます。
Windows の「設定」→「アプリ」→「インストールされているアプリ」で Meltype の「…」→「アンインストール」でも同じです。
(zip を展開したフォルダーが残っていれば、Uninstall.cmd をダブルクリックしても同じです)
停止・自動起動の解除・設定と学習データの削除まで行います。
