# Meltype のローマ字の表の見本: AZIK (拡張ローマ字) の撥音拡張・二重母音拡張
# 使うときは、%LOCALAPPDATA%\Meltype\dictionaries\romaji.txt (Mac・Linux はデータフォルダーの dictionaries/romaji.txt) に
# 写して、Meltype を起動し直してください。AZIK のすべての規則ではありません (よく使う語の短縮 (kt = こと など)・; の っ は入れていない)。
# 形式: 綴り<Tab>かな。綴りは英小文字だけ。ここに書いた綴りは、組み込みの綴りより優先します (kk は っ + k ではなく きん)。
